⚡ WebSocket

WS ws://<host>:8000/ws/monitor 실시간 ai:result 스트리밍

서버가 ai:result 스트림을 XREAD(block=1000ms)로 폴링, 새 항목을 JSON 텍스트로 push.

// 클라이언트 연결 const ws = new WebSocket("ws://localhost:8000/ws/monitor"); ws.onmessage = (e) => { const snap = JSON.parse(e.data); // UnifiedSnapshot console.log(snap.risk_level, snap.risk_score); }; // 수신 메시지 형태: UnifiedSnapshot (GET /status 응답과 동일 스키마)
연결 끊김 시 자동 제거. 다중 클라이언트 동시 연결 가능 (브로드캐스트).

📡 MQTT Broker: mqtt:1883 | Base topic: safewave | Protocol: MQTTv3.1.1

PUB safewave/ai/result AI 추론 결과 (매 프레임)

ai 서비스가 매 CSI 프레임 처리 후 publish. QoS 0.

{ "ts_ms": 1779943598722, "node_id": 1, "risk_level": "normal|warning|critical", "risk_score": 0.05, "slm_invoked": false, "reason": null, // M5 판단 근거 (slm_invoked=true 시) "is_outlier": false, "correlated_with_history": false }
PUB safewave/ai/emergency 경고/위험 이벤트 (risk_level = warning | critical 시)

동일 payload. Home Assistant automation trigger로 활용.

// HA automation.yaml 예시 trigger: - platform: mqtt topic: safewave/ai/emergency action: - service: notify.mobile_app data: message: "{{ trigger.payload_json.risk_level }} — node {{ trigger.payload_json.node_id }}"
SUB safewave/feedback 외부 피드백 수신 (HA → ai)

ai 서비스가 subscribe. 수신 payload를 Redis mqtt:feedback:last(TTL 1h)에 저장.

// HA MQTT publish 예시 - service: mqtt.publish data: topic: safewave/feedback payload: '{"confirmed": true, "node_id": 1, "action": "silenced"}'

스트림 (Redis Streams)

키생산자소비자maxlen보존 시간필드
csi:raw sensing ai 36,000 ~1시간 @ 10 Hz node int, ts_ms int, data bytes (float32[])
audio:events sensing (audio profile) / api ai 3,600 ~1시간 @ 1 Hz node int, ts_ms int, data JSON bytes
{sample_rate, channels, duration_ms, peak_db, waveform[]}
소비: ai가 csi:raw 트리거 시 xrevrange 역조회
ai:result ai api (XREAD) 36,000 ~1시간 @ 10 Hz data JSON bytes (UnifiedSnapshot)
ai:emergency ai (warning/critical 시) api alert_worker 3,600 ~1시간 data JSON bytes (EmergencySummary)

CSI vs Audio 저장 분리

csi:rawbinary float32 bytes, maxlen 36,000
audio:eventsJSON waveform list, maxlen 3,600
공통 원칙모든 키 TTL ≤ 1h, SSD 미사용

📊 신호 규격

CSI 패킷 포맷 (ESP32-S3 → sensing, UDP)

오프셋크기타입내용
01 byteuint8node_id (1~6)
11 byteuint8reserved
22 bytesuint16 LEn_samples
44 bytesuint32 LEtimestamp_ms (32-bit rollover)
8n_samples × 4float32[]CSI 진폭 샘플
수신률: 10 Hz (ESP32 송출 기준). 전처리 필터링 FS: 100 Hz (CSI_FS 환경변수). ONNX 입력: 512-sample float32 벡터.
