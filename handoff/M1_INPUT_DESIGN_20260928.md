# M1 재학습 설계 — 조건별 대안과 입력 설계 비교 (2026-09-28, 로컬)

작성: 노진산(통합). 대상: 김태연(M1), 팀.
근거는 빈 방 113분(09-23 22:02~23:54, 노드 1~4)과 같은 방 20:04 기록 120초다. 계산 결과는 `reports/laptop/m1_deep/input_design.json`에 있다.
**낙상 데이터가 없어서, 입력 설계는 '사람이 없을 때 얼마나 조용하고 안정적인가'로만 비교했다.** 낙상을 얼마나 잘 드러내는지는 사람이 있는 기록으로 확인해야 한다.

## 1. "같은 방에서 여러 상황으로 학습하면 강건해지나?" → 맞다. 단, '같은 방'은 한 조건이 아니다
| 비교 (노드별 두 프레임 타입의 평균 모양 거리, 1 − 코사인) | 노드 1 | 노드 2 | 노드 3 |
|---|---|---|---|
| 한 분 안에서 프레임끼리 흔들림(기준) | 0.0006 | 0.0025 | 0.0025 |
| 빈 방 113분: 처음 10분 대 마지막 10분 | **0.0001** | **0.0000** | **0.0001** |
| 같은 방 20:04 대 22시대(약 2시간 차이) | **0.062~0.069** | 0.010~0.013 | 0.016~0.022 |
| (참고) 같은 노드의 두 프레임 타입끼리 | 0.106 | 0.355 | 0.227 |

- 아무도 없고 아무것도 안 바뀌면 방의 배경 모양은 2시간 동안 **사실상 그대로**다.
- 같은 방이라도 2시간 전 모양은 **흔들림의 수십~백 배**만큼 다르다. 노드 1이 가장 크다. 20:04는 실험 준비 중이라 사람·노트북·문 상태가 달랐을 것으로 본다(미기록).
- 그래서 '정적 모양'을 외운 모델은 **같은 방에서도** 사람이 있었는지, 문이 열렸는지, 물건이 옮겨졌는지에 따라 무너진다. 9/16 모델은 같은 날 1.3%였지만 다른 날 96%였다.

→ 같은 방에서 학습하는 건 옳다. 단, 한 방 안의 여러 조건을 일부러 섞어야 한다.
- 여러 날·시간대
- 문 열림·닫힘, 가구·물건 위치
- 사람 있음·없음, 서 있는 위치
- 공유기 재부팅 전후

평가는 **학습에 안 쓴 날**로 한다.

→ 실제 서비스에서는 집마다 낙상 데이터를 모을 수 없다. 그래서 역할을 나누는 게 현실적이다.
- **낙상 판별**: 방과 무관한 '변화' 특징으로 여러 방에서 일반화한다.
- **배경**: 설치한 집에서 며칠간 라벨 없이 자동 보정한다(3절 B-3).

## 2. 입력 설계 후보 비교 (빈 방, 1초 창, 노드 1~4 범위)
| 설계 | 설명 | 잡음 바닥(중앙) | 변동계수 | 상위 0.1%/중앙 | 사용 프레임 | 판정 |
|---|---|---|---|---|---|---|
| D0 원 진폭(현재) | 프레임 그대로. 모델이 정적 모양을 봄 | 차분 기준 0.13~0.21 | 0.09~0.15 | 1.26~1.30 | 전부 | 혼재가 흔들림을 3~4배 부풀린다 |
| D1c 정적 제거(타입 무시) | 30 s 평균을 빼기만 함 | 0.11~0.19 | 0.01~0.04 | 1.02~1.07 | 전부 | ✗ 두 타입의 차이가 잔차를 채워서 움직임이 묻힌다 |
| D2 한 타입만 + 차분 | 펌웨어 필터 뒤 연속 프레임 차이 | 0.043~0.048 | 0.07~0.10 | 1.23~1.36 | **절반**(~35 Hz) | ○ 필터가 되면 쓸 수 있다 |
| **D1 타입별 정적 제거** | 프레임마다 **자기 타입의** 30 s 평균을 뺀 잔차 크기 | **0.028~0.037** | **0.04~0.06** | **1.15~1.20** | **전부**(~70 Hz) | ◎ 가장 조용하고 안정적이다. 혼재를 소프트웨어로 상쇄한다 |
| D1b 타입별 정적 제거 + 차분 | D1 잔차의 연속 차이 | 0.039~0.052 | 0.05~0.07 | 1.18~1.26 | 전부 | ○ |
| D3 모양 변화 | 1 − cos(프레임, 자기 타입 기준선) | 0.001~0.003 | 0.11~0.20 | 1.42~1.81 | 전부 | △ 상대 잡음이 크다 |

- D1은 **움직임이 없을 때 가장 낮고 고르게** 나온다. 사람 움직임이 같은 크기로 들어온다면 가장 잘 드러난다(신호대잡음 기준, 미검증).
- D1의 조건
  - 프레임마다 타입을 맞게 나눠야 한다. 노드별 2-평균 중심을 계속 갱신한다.
  - 20:04와 22시 사이에 노드 2의 다수 타입이 바뀌었다. 그래서 '다수 타입만 남기기'는 무너지지만, '**타입별로 따로 기준선을 두기**'는 어느 쪽이 다수인지와 무관하다.
- 누운 채 정지하면 30 s 뒤 기준선에 흡수된다. 낙상은 사건(변화) 감지로 잡고, 이후 상태는 음성 확인·무응답 규칙으로 판단한다.

## 3. 조건별 대안
### A. 프레임 혼재(두 타입 50:50)
| 대안 | 방법 | 장점 | 단점·위험 | 비용 |
|---|---|---|---|---|
| A-1 펌웨어 서명 고정(김태연 진행 중) | sig_mode·cwb·stbc·len으로 한 종류만 받음 | 근본 해결, 데이터가 깨끗함 | 새 프레임 비율 54~71%로 하락(김태연 추정). 트리거 재검토 필요 | 펌웨어 |
| A-2 공유기 설정 | 레거시 속도 끄기, 송신 안테나 1개, 20 MHz 고정 | 원인 제거 | 집 공유기를 바꿀 수 없음(서비스 불가). 실험실 전용 | 설정 |
| A-3 제조사 방식 트리거 | 공유기에 100 Hz ping, **ICMP 응답 프레임만** 수용(MAC + 길이) | 같은 종류 프레임이 규칙적으로 온다 | 트래픽 증가 | 펌웨어 |
| **A-4 허브 타입별 기준선(D1)** | 타입을 나눈 뒤 각자 기준선을 빼서 합침 | 프레임을 버리지 않음. 빈 방에서 가장 조용함. **지금 데이터로 바로 가능** | 타입이 3개 이상이거나 모양이 겹치면 오분류. 사람 데이터로 미검증 | 소프트웨어 |
| A-5 모델이 혼재에 무관하게 학습 | 학습 데이터에 타입 무작위 교대 증강 | 추가 장비 없음 | 신호가 약해진 채 학습됨 | 학습 |

### B. 배경(정적 모양) 의존
| 대안 | 방법 | 장점 | 단점 |
|---|---|---|---|
| B-1 입력에서 정적 제거(D1·D2) | 기준선 차감·차분 | 구조가 단순하다. 논문의 주된 해법(국소 분산 게이트 등) | 정지 상태 정보가 사라진다 → 사건 감지로 설계 |
| B-2 배경 바꿔 끼우기 증강 | 학습 창의 정적 성분을 다른 날·다른 방의 빈 방 배경으로 교체 | 기존 모델 구조 유지 | 빈 방 배경을 여러 개 모아야 한다(113분 기록 활용 가능) |
| B-3 설치 후 자동 보정 | 설치 뒤 며칠간 라벨 없는 생활 데이터로 노드별 기준선·정규화 학습 | 집마다 적응 | 초기 며칠은 보수적으로 운영 |
| B-4 라벨 없는 도메인 적응 | 대상 집의 빈 방·생활 데이터로 특징 분포를 맞춤(XFall류) | 성능 상한이 높다 | 구현이 복잡하다. 2주 안에는 어렵다 |
| B-5 이상 탐지로 전환 | 그 집의 '평소' 움직임 분포에서 크게 벗어난 급변을 탐지 | 낙상 라벨이 거의 필요 없다 | 격한 일상 동작도 이상으로 잡힌다 → 음성 확인 필수 |

### C. 수신 지터·빈 칸
| 대안 | 방법 | 비고 |
|---|---|---|
| C-1 보드 시계 + 노드별 굴림 오프셋 | 김태연 합의안 | 새 모델 전용(지금 모델은 포화) |
| C-2 보드 내 추론(N_pose) | 허브 정렬 문제가 사라짐 | 진행 중 |
| C-3 빈 칸 표시 채널 + 학습 시 무작위 누락 | 모델이 '빈 칸'을 신호로 오해하지 않게 함 | 지금 모델은 빈 칸에 반응한다(창 채움 ↔ 발화 상관 0.75) |

### D. 반복 프레임(표본 유지, 24~33%)
| 대안 | 방법 | 비고 |
|---|---|---|
| D-1 새 프레임 비트(CSI2에 있음) | 반복은 빈 칸으로 취급 | 필수 |
| D-2 목표 속도를 새 프레임 속도 아래로 | 50 Hz(새 프레임 약 67~76 Hz) | N_pose 방향과 일치 |
| D-3 불규칙 표본 그대로 사용 | 시각이 붙은 새 프레임만으로 특징 계산(D1처럼 1초 평균) | 모델 입력이 고정 격자가 아니어도 됨 |

### E. 노드 결합
| 대안 | 근거 |
|---|---|
| E-1 노드별 판정 + 2개 이상 투표 | 빈 방 노드별 잡음이 서로 무관하다(상관 0.00~0.02). 동시 초과가 0.08%로 곱처럼 줄어든다 |
| E-2 학습 시 노드 누락 증강 | 한 노드가 죽어도 동작 |
| E-3 거리 가중 | 가까운 노드는 반응이 크고(3.5배) 먼 노드는 작다(1.3배). 방 어디서든 가까운 노드 2개 이상 배치 |

### F. 데이터
| 대안 | 방법 | 비고 |
|---|---|---|
| F-1 같은 방 다양한 조건 | 1절 목록 | 가장 효과가 크다 |
| F-2 음성(비낙상) 데이터 우선 | 빈 방·앉기·눕기·물건 떨어뜨리기 | 운영 시간 대부분이 비낙상이다 |
| F-3 공개 데이터 사전학습 | 김태연 저장소에 CSI-Bench 라벨 파일이 있음 | 장비(Intel 5300 등)와 ESP32 차이가 크다 → 특징(D1 등)을 맞춰야 한다 |
| F-4 라벨 시각 정확도 | 영상 동시 촬영으로 마커 지연 실측 | 김태연 계획과 같다 |

### G. 판단 규칙
- 5초 평균 + 히스테리시스로 판단 바뀜이 분당 16.8회에서 0.26회로 줄었다(개선안 문서 D절).
- 음성 확인과 소리(M3·M4) 보강을 같이 쓴다.

## 4. 관점별 정리
| 관점 | 핵심 |
|---|---|
| 신호(물리) | 낙상은 '변화'다. 배경 모양은 방·날·물건마다 바뀌므로 입력에서 빼야 한다(D1·D2) |
| 데이터 | 양보다 조건 다양성이다. 같은 방도 조건을 바꿔 모으고, 안 쓴 날로 평가한다 |
| 시스템 | CSI는 '급변 감지기'로 쓰고, 낙상 확정은 소리·음성 확인과 겹쳐서 한다. 단독 확정은 새 모델 합격 뒤 |
| 운영 | 집마다 배경을 자동 보정한다(B-3). 초기엔 보수적으로 운영한다 |
| 일정(10/12) | 2주 안에 가능한 것: A-1(진행 중), D1 특징 검증(5분 기록), E-1 투표, G 규칙. 어려운 것: B-4 도메인 적응, 대규모 수집 |

## 5. 제안 순서
1. **5분 사람 기록**(노트북 수신 + 영상): D1·D2가 걷기·앉기·모의 낙상에서 빈 방 대비 몇 배 오르는지 확인
2. 효과가 확인되면 N_pose 입력을 원 진폭에서 **D1(타입별 정적 제거)** 또는 필터 후 D2로 바꾼다. 김태연과 합의한다.
3. 수집은 같은 방 다양한 조건(F-1) + 다른 날 빈 방으로 하고, 평가는 학습에 안 쓴 날로 한다.
4. 허브 규칙: 노드별 판정 → 2개 이상 → 5초 히스테리시스 → 음성 확인
