# 회신 — 집계·격자 수정 반영 (2026-09-17 저녁)

김태연님 답변(「집계 해석, 격자 기준, CSI2 조건」) 반영했습니다. 코드·단위 테스트만 확인했고
RPi5 재측정은 아직입니다.

## 반영

| 답변 | 반영 |
|---|---|
| 1. 생략 tick = 0으로 N에 포함 (a) | 200ms tick이 추론 없이 끝나면 그 tick을 0표로 K/N 창에 넣습니다(`record_skipped_m1_ticks`). 같은 tick 안에서는 타이머를 전진시키지 않고 기다리는 동작은 그대로입니다. 추론 실패·타임아웃도 0표입니다. 창이 안 찬 구간(필수 노드 버퍼 부족)도 0표로 세고 `input_status=insufficient_input`으로 표시합니다 |
| 3. zero-fill 격자 `stream_id` 기준 | 수신 시각(stream id ms)을 `round(t/10)` 전역 슬롯으로 스냅합니다(±5ms). 빠진 슬롯은 0, 창 길이까지만 채웁니다. 장치 시계(`ts_ms`)·uint32 wrap·늦은 패킷 처리는 제거했습니다 |
| 4. 게이트 허용치 15ms | `M1_TAIL_MAX_AGE_MS` 기본 15ms. RPi5에서 10/15 두 값을 모두 재겠습니다 |
| 7. `M1_REQUIRED_NODES` 환경변수 | 이미 환경변수입니다(기본 `1,2,3`). 5노드 모델이면 `.env`에 `1,2,3,4,5`만 바꾸면 됩니다 |
| 8. 게이트 제거 대비 | `M1_TAIL_MAX_AGE_MS=0`이면 창끝 게이트를 끕니다(재빌드 불필요) |
| 2·5·6 | 현재 처리 유지, CSI2는 펌웨어 공유 후 조건대로 진행(10/05 종료) |

추가로, M1은 노드 1·2·3을 함께 보는 모델이라 M5 없이 나가는 규칙 경보(3/5 확정)를 노드별이 아니라
전역으로 한 번만 내도록 바꿨습니다. RPi5에는 60초마다 `m1_gate_stats` 로그(추론 수/기대 수,
창 미충족, 창끝 누락, 0 채움 프레임, 슬롯 충돌, 생략 tick)가 남습니다.

## 확인 부탁

1. **같은 슬롯에 두 프레임이 스냅될 때** 학습 로더는 어느 쪽을 남기나요? 지금은 최신 프레임으로
   교체합니다(`slot_collisions`로 횟수 기록). 먼저 온 것을 남기거나 평균이라면 맞추겠습니다.
2. **격자 원점**은 노드와 무관한 전역 `round(stream_ms/10)`으로 두었습니다. 학습 로더가 세션 시작
   시각 등 다른 원점을 썼다면 알려 주세요.
3. 노트북 부하 시험(합성 CSI, 1% 손실·2ms 지터)에서 추론 수는 분당 기대 300회 중 296~298회였습니다.
   합성 입력에서도 M1이 3/5로 양성을 내서 규칙 경보가 났습니다. 학습 분포 밖 입력이라 오탐률 근거는
   아니지만, 빈 방 실측 전까지 규칙 경보의 오알림 가능성은 열어 두겠습니다.
