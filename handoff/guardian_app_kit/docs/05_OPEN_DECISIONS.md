| D6 | 음성 전사·클립 | 표시 안 함 / 키워드만 / 전사 표시 / 클립 재생(P2, 동의 필요) | 키워드만 | |
| D7 | 배포 방식 | APK 사이드로딩 / Play 내부 테스트 | 사이드로딩(배터리 예외·FSI 안내가 단순) | |
