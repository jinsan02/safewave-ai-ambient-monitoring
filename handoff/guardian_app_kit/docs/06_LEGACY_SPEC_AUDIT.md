# 예전 문서 「고신뢰성 긴급 사고 전파 시스템」 검토 결과

검토 기준: 현재 서버 코드·RPi5 실측(2026-09-17), Android 14+ 정책, 대상 기기(플립4).

## 1. 살린 것 (MVP에 반영)

| 예전 항목 | 반영 방식 |
|---|---|
| 01 잠금 화면 가시성 (Full Screen Intent) | F2. Android 14+ 사용자 허용 필요 → 온보딩 안내 + 거부 시 단계적 저하 |
| 01 고대비 UI·대형 폰트 | 기능 명세 7절 UI 원칙 |
| 02 무음/진동 우회 (`USAGE_ALARM`) | F3. 알람 스트림 재생, 음량 복구 포함 |
| 03 방해금지 예외 | 채널 예외 + 사용자 허용 안내(강제 우회 아님) |
| 대응 시나리오 — 원터치 119 | F4. 전화 앱을 번호가 채워진 상태로 열기(자동 발신 아님) |
| 배터리 최적화 대응 | F1·F9 온보딩 안내, 권한 꺼짐 배너 |
| 권한 해제 감지 | F9(앱 실행 시). 앱 삭제 감지는 서버 토큰 만료로 P1 |
| 2차 보호자 | F10. 동시 수신(서버 이미 지원) |

## 2. 고쳐서 반영

| 예전 내용 | 문제 | 변경 |
|---|---|---|
| "SLM 분석 결과 확정 시" 트리거 | 현재는 **규칙 경보가 먼저**(M5 없이), M5는 보조 | 트리거: `ai:emergency` critical(규칙 또는 M5) |
| Qwen-0.5B | 현재 Qwen2.5-1.5B GGUF | 문서 갱신 |
| WakeLock으로 화면 강제 깨움 | 구식·불필요 | Activity `setTurnScreenOn` |
| "1차로 스마트 비서 안부 → 무응답 시 강제 알림" | 30초 지연. 현재는 즉시 푸시 후 음성 확인 | D2 결정 사항으로 |
| 3분 미확인 시 TTS 자동 전화·SMS | 확인(ack) API가 없고 외부 서비스 필요 | P1 재발송(S10) → P2 전화·SMS |

## 3. 뺀 것

| 예전 내용 | 이유 |
|---|---|
| 사고 전후 30초 음성 클립 | 마이크는 소리가 날 때만 최대 6초 조각 저장(연속 녹음 없음), `ai:clip`은 메타데이터만, FCM 4KB 한도, 집 밖에서 서버 불통, 대상자 동의 절차 없음 → P2 |
| "욕실 낙상" 등 장소 | M1은 노드 1·2·3을 합쳐 판단 → 위치를 알 수 없음. 경보의 노드 번호는 위치가 아님 |
| "충격음 후 1분간 움직임 없음" 요약 | 무활동 감지 기능 없음(M1은 낙상, M2는 미학습) |
| AI 근거로 CSI 파형 로그 첨부 | 원본 약 2분만 보관, 보호자에게 의미 없음 → 투표 수(3/5)·판단 경로만 |
| 접근성 서비스 오버레이, Restricted Settings 해제 안내 | 정책 위반·보안 우회 안내 |
| `setRingerMode`/무음 강제 해제 | 사용자 설정 변경, 방해금지 중 권한 없이 실패 |
| `specialUse` 포그라운드 서비스, `ROLE_EMERGENCY`, 정확 알람 | 불필요·일반 앱 불가 |
| iOS Critical Alerts, Emergency Bypass | 대상이 Android. Apple 승인 필요 |
| Twilio·Node-RED IVR | 유료 외부 서비스, Node-RED는 JS(서버 저장소 규칙 Python) → P2에서 Python으로 재검토 |
| 지자체 관제센터 연계, 스마트 스피커 원격 대화 | 기관 협약·양방향 음성 필요 → P2 |
| TurboQuant, RVF, CSI_ratio, MM-Fi 포즈 추정 | 현재 시스템에 없음 |
| "도달률 95% 이상 보장", "오탐률 0.1% 미만", "원천 차단", "완벽히 보호" | 측정 근거 없음. M1 빈 방 관찰 118초뿐 → 표현 삭제, 실기기 확인표로 대체 |

## 4. 예전 문서에 없던 것 (추가)
- **서버 푸시 형식(S0)**: notification+data로는 앱 종료 상태에서 전체 화면·반복 사이렌 불가
- **원격 접속(D1)**: 집 밖 보호자는 REST에 닿지 않음
- **시스템 정지 감지(P1-2)**: RPi5·전원·인터넷이 멈추면 알림이 없고 보호자는 "조용함 = 안전"으로 오인
- **확인·오탐 신고 경로(S2·S3)**: 오탐 필터링을 말하려면 피드백 수단이 필요
- **보안(D5)**: 인증 없는 API는 같은 네트워크의 누구나 토큰을 바꿔 알림을 가로챌 수 있음
- **Firebase 키·같은 프로젝트**: 없으면 알림 자체가 안 나감
- **같은 노드 90초 재경보 억제**: 그 사이 두 번째 사고는 알림 없음 → 앱 안내 문구
