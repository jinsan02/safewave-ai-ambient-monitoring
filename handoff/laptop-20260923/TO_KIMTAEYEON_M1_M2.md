# M1·M2 공유 — 노트북 실측 (2026-09-23, 김태연 님께)

작성: 노진산(통합). 노트북 실험 결과라 RPi5 성능 수치와는 다르지만, **입력 데이터와 오경보 현상은 RPi5에서도 같다**고 봅니다.

## 실험 조건
| 항목 | 값 |
|---|---|
| 센서 | 실제 ESP32 4노드 → 노트북(192.168.1.11) UDP 5005, 각 100 Hz |
| 방 | **빈 방**(사람 없음), 2026-09-23 22:02 ~ 23:54(113분. 23:55~23:57은 제외) |
| 모델 | `m1_wifi_pose_onnx`(3노드 학습, 입력 `(1,5,64,100)`, 임계 0.80), 5회 중 3회 투표, 필수 노드 1·2·3 |
| 입력 조립 | 수신 시각(stream id) 기준 100 Hz 격자, 창끝 게이트 15 ms, 추론 200 ms마다 |
| 코드 | develop `5d85860` |

## 1. 빈 방인데 낙상 경보가 계속 납니다 (가장 중요)
- M1 규칙 경보 "낙상 확정(M1 3/5·5/5)" **113분에 65건(시간당 약 35건)**: 노드 1 19건, 2 14건, 3 20건, 4 12건(경보 기록 노드 기준).
- 빈 방 M1 점수가 **0.3~0.94** 사이를 오갑니다(5분 간격 표본 19회: 0.80 이상 6회, 0.5~0.8 10회, 0.5 미만 3회. 같은 표본에서 5회 중 3회 투표가 낙상 확정인 경우 8회).
- 이 경보가 90초마다 나서 M5·보호자 알림이 사실상 오경보로 채워집니다.

확인 부탁
1. 학습 때 빈 방(음성 표본) 데이터가 있었는지, 그때 점수 분포가 어땠는지
2. 이 방·센서 배치가 학습 때와 다른 점(거리·높이·노드 위치) — 배치 사진 필요하면 찍겠습니다
3. 아래 2·3번(입력 특성)이 학습 데이터와 같은지

## 2. 패킷은 거의 다 오지만, 도착 시각이 몰립니다
| 항목 | 값 |
|---|---|
| 수신률 | 노드별 99.997~99.999%(22:02~23:46 감사, 빠진 패킷 노드당 4~20개), NaN·빈 패킷 0 |
| 도착 간격 | p50 9 ms / p95 22 ms, **약 8%가 앞 패킷과 1 ms 이내에 도착** |
| M1 격자 | 분당 추론 297/300(중앙값), **0으로 채운 칸 분당 3,400(876~6,987)**, 같은 칸 충돌도 거의 같은 수 → 창의 약 13%가 0 |
| 장치 시각 | 2분 기록 중 세 노드 동시에 한 번 2.1 s 건너뜀(손실 없음) |

패킷이 빠져서가 아니라 Wi-Fi 전송이 몰려 수신 시각 격자에서 칸이 비는 현상입니다. **장치 시각(`ts_ms`)이나 순번으로 칸을 정하면** 대부분 없어질 것으로 봅니다.
→ 학습 로더도 수신 시각 격자였는지, 장치 시각 기준으로 바꿔도 되는지 의견 부탁드립니다(이전 회신의 격자 원점 질문과 같은 건).

## 3. raw 블록의 0 값 (첨부 `csi_zero_stats_20260923_2347.xlsx`)
- **항상 0인 12채널**: 0~5, 32, 59~63(Wi-Fi 20 MHz 보호 대역·DC). raw·resp·heart 모두 같음 → 실제 정보는 52채널.
- **노드 2만** 추가로 0이 자주 나옵니다: 행의 **59%**에서 1~4개 채널이 추가로 0. 채널 37(14.7%), 53(13.7%), 45(12.4%), 29(9.6%), 14, 22, 6, 52, 21 — 29·37·45·53이 8칸 간격.
- 노드 3은 채널 58이 1.9%, 노드 1·4는 추가 0이 거의 없습니다.
- 노드 2는 RSSI가 가장 셉니다(-37 dBm). 증폭 포화나 raw peak-norm 양자화를 의심합니다(펌웨어 확인 필요).

→ 학습 데이터에도 이런 채널 0이 있었는지, 모델이 이 채널에 민감한지 확인 부탁드립니다.

## 4. 노드 4·5
노드 4가 온라인이지만 M1은 코드상 1·2·3만 채우고 4·5 칸은 0입니다(학습 조건 유지). 4·5를 쓰려면 재학습이 필요한지, 온라인 노드만 채워도 되는지 의견 부탁드립니다.
(`M1_REQUIRED_NODES`에 넣으면 필수 노드가 되어 하나만 꺼져도 M1이 멈춥니다.)
