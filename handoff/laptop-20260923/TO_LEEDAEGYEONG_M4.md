## 3. 환각 (공유가 필요한 부분)
노트북 USB 마이크로 방 소리를 받을 때(VAD -45 dB), 조용하고 짧은 조각에서 없는 문장이 나왔습니다.
- **"MBC 뉴스 이덕영입니다" / "이준석입니다" / "이범귀입니다"** 등: 0.3~0.5초, 최대 음량 -38 dB 이하 조각
- "감사합니다", "경제였습니다", "날씨가 좋았다"
- 반복형: "기사에 비해 국가대표의 정책에 비해 국가대표의 정책에 비해 …"
- **위험한 것**: 잡음 조각에서 "도와줘", "너 죽어", "넘어져보이잖" → 긴급 키워드 오경보로 이어질 수 있음

통합 쪽 임시 조치: 노트북 VAD를 -35 dB·최소 500 ms로 올려 조각 수를 줄였습니다(RPi5는 -45 유지).
보류 중인 제안(의견 부탁드립니다):
1. 알려진 환각 문장 제거(“MBC 뉴스 … 입니다”, “시청해 주셔서 감사합니다”, “구독과 좋아요” 등)
2. 너무 짧거나(예: 0.5초 미만) 작은 조각은 전사 결과를 버리기
3. 반복 방지 guard(인계 때 주신 wrapper) 통합 — 아직 미통합

참고: M3 병합으로 sensing이 **조용한 이벤트를 peak 0.85까지 증폭**한 뒤 보냅니다(M4 입력도 증폭됨). 환각에 영향이 있는지 봐 주시면 좋겠습니다.

## 4. 속도
| 환경 | M4 1회 | RTF |
|---|---|---|
| RPi5 INT8(9/17) | 4.43 s | — |
| 노트북 CPU 2스레드(RPi5 설정) | 1.00 s | 0.38 |
| 노트북 CPU 8스레드 | 0.65 s | 0.19 |
| 노트북 GPU | 0.47 s | 0.14 |

- GPU에서는 INT8 연산 상당수가 CPU로 돌아가 CPU↔GPU 복사 노드가 168~268개 생깁니다. GPU용이라면 **FP16 모델**이 더 빠를 것 같습니다(필요하면 비교해 보겠습니다).
- 통합 쪽에서 GPU 모드일 때 transformers pipeline이 모델을 CPU로 되돌리던 문제를 고쳤습니다(`b23ad5f`, `device=model.device`).

## 5. 09-24 통합 쪽 후처리 — 환각 거르기·긴급 문장 유사 매칭 (모델 가중치 변경 없음)
`ai/experts/m4_whisper_small.py`(통합 래퍼)만 바꿨습니다. 공유드리고 의견 부탁드립니다.

**원인 재현** (`scripts/dev/m4_hallucination_probe.py`, 결과 `reports/laptop/m4_hallu_svc.*`)
- 완전 무음 → 3회 모두 "도와주셨습니다". 생활 소음 80구간 → 80개 모두 문장("MBC 뉴스 이덕영입니다" 20회, "경제였습니다", 반복 문장 등).
- Whisper는 말이 없어도 학습 자막에 흔한 문장을 만들고, 우리가 쓰던 transformers pipeline은 원본 Whisper의 '말 없음' 검사를 하지 않았습니다.
  파인튜닝 모델은 "도와…" 쪽 환각이 잦아 말 아닌 소리 169개 중 28개(17%)에 긴급 키워드가 들어갔습니다.
- 기존 `stt_confidence`는 2026-05-28(ver.0.0.2) 통합 쪽 임시 고정값 0.75였습니다.

**바꾼 것**
| 항목 | 내용 |
|---|---|
| 디코딩 경로 | pipeline 대신 encoder 1회 → decoder 1스텝으로 첫 위치 `<|nocaptions|>` 확률 → 같은 encoder 출력으로 `generate`(설정 동일: ko, transcribe, greedy, max 48) |
| 환각 판정 | '말 없음' 확률 > 0.05, 또는 (> 0.005이면서 토큰 평균 로그확률 < −0.5) → 전사·키워드 버림. 원문은 `transcript_raw` |
| 확신도 | `stt_confidence = (1 − 말 없음 확률) × exp(평균 로그확률)` |
| 긴급 문장 유사 매칭 | 평가셋 라벨의 긴급 문장(도와주세요·살려주세요·사람 살려·신고해 주세요·119/구급차 불러 줘·넘어졌어요·미끄러졌어요·쓰러졌어요·못 일어나겠어요·불이야·숨을 못 쉬겠어요)과 발음 기준 자모 편집거리(연음·받침 대표음, 비슷한 소리 0.5) 유사도 ≥ 0.8 → `emergency_phrase_detected`. 짧은 문장(자모 8개 미만)은 0.95 이상만 |
| 새 출력 키 | `emergency_phrase`, `emergency_phrase_sim`, `emergency_phrase_detected`, `no_speech_prob`, `avg_logprob`, `hallucination_filtered`, `transcript_raw` |
