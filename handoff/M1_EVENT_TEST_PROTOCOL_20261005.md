## 6. CSI 기록을 다른 사람에게서 받는 경우
**김태연 필터 펌웨어 기록**이면 품질 지표를 비교한다.
- 혼재 ≤ 15%, 새 프레임 ≥ 85%
- 재는 법: `m1_false_alarm_analysis.py`의 데이터 계약 항목, 또는 이 스크립트의 `summary.json` → `contract`

**CSI2(280 B, 50 Hz) 형식**이면 열 이름이 다르다.
- 김태연 `hub/receiver.py`의 CSV 형식을 받은 뒤 `load()`에 변환을 추가한다(지금은 미지원).
- 50 Hz면 급변 기준선 예열(30 s)·창(1 s)은 그대로 쓰고, 새 프레임 속도만 다시 잰다.
